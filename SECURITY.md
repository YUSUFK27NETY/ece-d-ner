# Güvenlik politikası

Güvenlik açığını herkese açık issue içinde müşteri verisi, erişim anahtarı veya istismar ayrıntısıyla paylaşmayın. Depo sahibine özel bir kanaldan şu bilgileri iletin:

- Etkilenen sayfa veya API yolu
- Tekrarlama adımları
- Beklenen ve gerçekleşen sonuç
- Varsa kişisel veri etkisi

Parola, Firebase servis hesabı, erişim tokenı ve tek kullanımlık giriş kodları hiçbir zaman repoya veya ekran görüntüsüne eklenmemelidir. Yanlışlıkla paylaşılan bir sır yalnız silinmemeli; ilgili sağlayıcıda derhal iptal edilip yenilenmelidir.
